# numerical-gradient-optimization
This repository provides a collection of optimization algorithms and techniques implemented purely with NumPy. It includes various gradient-based methods such as Stochastic Gradient Descent (SGD), Nesterov Accelerated Gradient (NAG), and other advanced optimization strategies, all designed for numerical function minimization tasks. The focus is on demonstrating the power of basic linear algebra operations in solving complex optimization problems, offering a hands-on approach to understanding and implementing machine learning and computational optimization techniques from scratch. Ideal for researchers, students, and practitioners interested in the mathematical foundations of optimization algorithms without relying on high-level libraries.
